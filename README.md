# Al Amin — Personal Portfolio (AI Practical Assessment, Task 04)

Live site (GitHub Pages): https://alamin04-crypto.github.io/al-amin-portfolio/
(If the repository name is different, replace `al-amin-portfolio` in the URL above with the actual repository name.)

## What this site is

A single-file, responsive personal portfolio for Al Amin, built for Task 04 of the
AI Practical Assessment (Claude AI | Creative Production | Digital Marketing).

Sections: Hero, About Me, Skills & Expertise, Services, Portfolio / Projects,
Experience & Education, Testimonials, and Contact — with a sticky navigation
menu, working project filter, and functional contact buttons and form
(the form opens the visitor's email app with the message ready to send).

## Content, honestly stated

- Experience and education use only verified facts: Bangladesh Army service
  (February 2022 – January 2025) and BBS at Chandpur Government College (ongoing),
  plus AI skills training.
- Projects are real completed works (motion videos, perfume promo and ads copy,
  design set, calendar, demo shop, podcast guide). No invented clients or results.
- Testimonials: no reviews have been invented. The section states that real
  client feedback will be added there with permission.
- Skill levels are self-assessed and labelled as such on the site.

## Prompt used (Claude AI)

> Create a professional, modern and minimal personal portfolio website for
> Al Amin, a digital services professional from Bangladesh. Include: a hero
> section with name, professional headline and CTAs; About; Skills with
> self-assessed levels; six Services (Customer Support, Video Editing, Web
> Development, App Development, Media Buying & Facebook Ads, AI Creative
> Content); a filterable Projects section with eight real projects;
> Experience & Education timeline; a Testimonials section without invented
> reviews; and a Contact section with working buttons and a form. The site
> must be responsive on mobile, tablet and desktop, use a navy and gold
> palette with the Inter font, smooth navigation, and a single HTML file
> with inline CSS and JavaScript, ready for GitHub Pages.

## Tools used

- Claude AI (planning, content and code)
- HTML, CSS and JavaScript (single file, no build step)
- GitHub Pages (publishing)

## How to update it

Edit `index.html` only. Contact details live in one place at the bottom of the
file, in the `CONTACT_EMAIL`, `CONTACT_PHONE` and `CONTACT_TELEGRAM` variables.
To add a photo, replace the gold "AA" monogram block in the hero with an
`<img>` tag pointing to your photo file in this repository.
